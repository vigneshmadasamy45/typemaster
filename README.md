# ⌨️ TypeMaster

A modern, interactive typing speed test designed to help users improve their typing speed, accuracy, and consistency.

🌐 **Live Demo:** https://vigneshmadasamy45.github.io/typemaster/

---

## ✨ Features

- ⚡ Real-time WPM calculation
- 🎯 Accuracy tracking
- 📊 Typing rhythm visualization
- 🏆 Personal best tracking
- 📈 Average WPM calculation
- 📝 Local typing history
- 🎚️ Easy, Medium, and Hard difficulty levels
- ⏱️ 15, 30, 60, and 120 second tests
- 🔤 Word-based typing mode
- 💻 Code typing mode
- 🧠 Adaptive practice for weak keys
- 🌙 Dark and Light themes
- 🔊 Optional typing sounds
- 🎯 Focus mode
- ⌨️ Interactive keyboard visualization
- 🔄 Restart and retry functionality
- 📱 Responsive design for mobile devices
- 💾 Local storage for saving progress and preferences
- 🚫 Caps Lock warning
- ⏸️ Automatic pause when the browser loses focus

---

## 🎮 How to Use

1. Open the TypeMaster website.
2. Select a difficulty level.
3. Select the test duration or word mode.
4. Click inside the typing area.
5. Start typing the displayed passage.
6. Type as accurately and quickly as possible.
7. View your WPM, accuracy, consistency, and detailed results.

## 📊 Performance Metrics

After completing a test, TypeMaster displays:

- Net WPM
- Raw WPM
- Accuracy
- Consistency
- Correct characters
- Incorrect characters
- Missed characters
- Test duration
- Personal best
- Average WPM
- Typing rhythm chart

---

## 🧠 Adaptive Practice

TypeMaster records frequently mistyped keys locally and can generate practice passages focused on those weak keys.

This allows users to specifically practice the characters they struggle with.

## 🎨 User Interface

TypeMaster includes:

- Modern glass-style interface
- Gradient backgrounds
- Animated typing cursor
- Live progress bar
- Interactive keyboard
- Result animations

- Dark/Light theme support
- Responsive mobile layout

---

## 🔐 Privacy

TypeMaster does not require an account or server.

Typing history, preferences, and weak-key information are stored locally in the browser using `localStorage`.
